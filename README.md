# Wonnder Remote — сборки для Windows

Здесь лежит только установщик: **исходники в отдельном приватном
репозитории**, и попасть сюда они не могут — ассеты уходят через Releases API,
который умеет файлы и не умеет коммиты.

Установщик хоста — программы, которая отдаёт экран этого компьютера и
принимает управление. Смотрят с телефона: приложение для Android лежит в
[wonnder-remote-android](https://github.com/TheWonnder/wonnder-remote-android).

Свежая версия — на вкладке [Releases](../../releases/latest). Программа
проверяет её сама и предлагает обновиться; здесь она нужна для первой
установки и на случай, если обновиться нечем.
